# AI-агент для Instagram — Laser Electro Epilace Praha

Агент сам придумывает, рисует и публикует посты и сторис с **вымышленными людьми** для рекламы студии.

## Как он работает

1. **Планирует** (Claude): выбирает рубрику из `brand.yaml`, придумывает идею, вымышленную модель (возраст, внешность, образ), промпт для фото, заголовок на картинке, подпись на чешском (+ украинском) и хэштеги. Он смотрит в `history.jsonl`, чтобы не повторять идеи и лица.
2. **Генерирует фото** через выбранный сервис: OpenAI, Google Gemini или Replicate (Flux).
3. **Проверяет** (Claude смотрит на картинку): лишние пальцы, «пластиковая» кожа, случайные надписи, человек выглядит несовершеннолетним, откровенность. Если что-то не так, агент исправляет промпт и генерирует заново (до 2 раз).
4. **Оформляет**: обрезает до 1080×1350 (пост) или 1080×1920 (сторис), накладывает заголовок, кнопку и логотип в фирменных цветах. Для сторис учитываются зоны, которые закрывает интерфейс Instagram.
5. **Публикует**: загружает картинку в Supabase Storage и ставит её в расписание Metricool с автопубликацией. Публикация получает метку Instagram «Создано с помощью ИИ».

## Настройка (один раз)

1. **Ключи**: скопируйте `.env.example` в `.env` и заполните.
   - `ANTHROPIC_API_KEY`: console.anthropic.com
   - ключ генератора картинок, который выбран в `IMAGE_PROVIDER`
   - **Supabase**: создайте **публичный** bucket `instagram` (Storage → New bucket → Public) и возьмите `service_role` ключ
   - **Metricool**: Настройки аккаунта → API → `userToken`; `userId` и `blogId` указаны там же (нужен тариф с API)
2. **Бренд**: проверьте `brand.yaml`, особенно ник в Instagram, рубрики, цены и время публикаций.
3. Шрифт: по умолчанию Inter или DejaVu. Чтобы задать свой, положите файлы `fonts/bold.ttf` и `fonts/regular.ttf`.

## Запуск вручную

```bash
cd instagram-agent
pip install -r requirements.txt
set -a; source .env; set +a

python agent.py run --no-publish                 # только сделать картинки в output/
python agent.py run                              # сделать и поставить в расписание
python agent.py run --brief "Black Friday: -20 % na celé nohy" --posts 1 --stories 3
python agent.py run --provider gemini            # сменить генератор на один запуск
python agent.py run --provider mock --no-publish # бесплатный тест без генерации
```

## Полностью автоматически (GitHub Actions)

Файл `.github/workflows/instagram-agent.yml` запускает агента каждый день утром. Агент готовит контент на завтра, а файл `history.jsonl` сохраняется в репозиторий.

1. GitHub → Settings → Secrets and variables → Actions → добавьте секреты с теми же именами, что в `.env.example`.
2. Там же во вкладке *Variables* задайте `IMAGE_PROVIDER` (`openai` / `gemini` / `replicate`).
3. Разовый запуск с заданием: Actions → Instagram agent → Run workflow → поле «brief».

Готовые картинки каждого запуска сохраняются как артефакт в Actions.

## Правила, встроенные в агента

- Все люди вымышленные и взрослые, разного возраста, пола и типажа. Агент не создаёт похожих на реальных людей и знаменитостей.
- Никаких фейковых отзывов и выдуманных результатов «до/после», никаких обещаний «навсегда» и «100 %». Используются только цены из `brand.yaml`.
- Каждая публикация помечается как созданная ИИ (требование Instagram и EU AI Act для синтетических изображений людей).
